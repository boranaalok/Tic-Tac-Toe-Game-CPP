# 🎮 Tic Tac Toe Game in C++

## 📌 Project Overview

This project is a console-based Tic Tac Toe game developed using C++. The game allows two players to play against each other using X and O symbols.

The project demonstrates core programming concepts such as arrays, loops, conditional statements, functions, and user input handling.

It provides an interactive gaming experience with dynamic board display, win detection, draw detection, and replay functionality.

## 🚀 Features

- Two-player gameplay (X and O)
- Interactive 3×3 game board
- Dynamic board display after every move
- Win detection for rows, columns, and diagonals
- Draw detection
- Input validation
- Prevents players from selecting occupied positions
- Replay functionality
- Console-based interface

## 🛠️ Technologies Used

- Programming Language: C++
- Compiler: GCC
- IDE: Visual Studio Code
- Concepts: Arrays, Loops, Functions, Conditional Statements

## 🎯 How to Play

1. The game starts with Player X.
2. Players take turns entering a number from 1 to 9.
3. Each number represents a position on the game board.
4. The first player to complete a row, column, or diagonal wins.
5. If all positions are filled without a winner, the game ends in a draw.
6. Players can choose to replay the game.
